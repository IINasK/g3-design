Seu agente. A mesma linguagem.

Requer Node.js 22.20+ e Git. A instalação é feita somente neste projeto.

npx --yes skills@1.7.6 add IINasK/g3-design --skill g3-design --agent claude-code --copy --yes

Depois de instalar, peça ao agente para usar a skill G3 Design.
